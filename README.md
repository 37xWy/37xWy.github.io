# Portfolio Website (37xWy.github.io)

Personal portfolio website built to showcase my projects, technical skills, and software engineering journey as an AI-specialized Computer Science student at APU.

## 🚀 Built With
- **Framework:** [React](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Routing:** [React Router (HashRouter)](https://reactrouter.com/)
- **Styling:** Custom CSS with a responsive design
- **Deployment:** GitHub Pages

## 📂 Project Structure
- `src/`: Core application logic, components, and project data.
- `public/images/`: Optimized media assets and case study demonstrations.
- `data.js`: The central "database" for all project metadata and case study content.

## 👨‍💻 About Me
I am a Year 2 Computer Science student specialising in AI. My passion lies in software automation, computer vision, and building efficient, modular code.
